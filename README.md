# SabhyaBacchi — Pooja's portfolio

Static site, no build step. Open `index.html` or deploy the folder as-is (Netlify / Vercel / GitHub Pages).

## Structure
- `index.html` — home page
- `about/index.html`, `my-work/index.html` — generated by `build-pages.py` (edit the ABOUT / MY_WORK strings there, re-run `python3 build-pages.py`)
- `assets/pooja-cutout.png` — transparent photo used on About
- `assets/work/` — Minimalist case-study media (brand/, carousels/, reels/)
- `assets/` — images, 12 stylesheets (`style0–11.css`), fonts
  - `friend-paper.png` — hero photo (Pooja on torn-paper backing)
  - `img0.png` — title artwork (replace with hand-drawn "SabhyaBacchi")
  - `img1.png` — hand with pen · `img2/3/5.png` — the three stars
- `universal/svg/social-accounts.svg` — footer social icons
